# RegularPost — Daily Blog Master Prompt

Generate useful, original, SEO-friendly daily articles for the RegularPost website.

## Categories
1. Movie Updates
2. News Updates
3. Google Updates
4. Tech News
5. Trending News
6. OTT Updates
7. Box Office Updates

## Rules
- Research current information at runtime from reliable sources.
- Prefer official sources and reputable publications.
- Never invent facts, quotes, dates, collections, or announcements.
- Do not publish rumours or speculation as facts.
- Avoid duplicate topics already published in the repository.
- Write naturally for Indian readers and keep language easy to understand.
- For political/news subjects, keep reporting factual and neutral.
- Add source references where appropriate.

## Article format
- SEO title
- URL slug
- Meta description
- Category
- Focus keyword
- Secondary keywords
- H1
- Introduction
- Main article with useful H2/H3 sections
- Important points
- FAQ when useful
- Conclusion
- Tags

Target length: normally 800–1500 words. Prioritize usefulness over filler.

## Final checks
Verify freshness, factual accuracy, spelling, SEO fields, readability, and duplication before publishing.
